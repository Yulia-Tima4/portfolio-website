## 📝 О проекте

Этот сайт создан с использованием **ИИ-инструментов** — как вспомогательного средства для вёрстки.

Я — **QA Engineer**, а не фронтенд-разработчик. Этот сайт — демонстрация того, что я **умею работать с современными инструментами** и **оценивать результат**: адаптивность, работу ссылок, читаемость контента.

**Идея, структура, тексты и подбор проектов — мои.**

Считаю, что ИИ — это инструмент для повышения эффективности, но **качество результата по-прежнему требует проверки**. Собственно, это и есть суть работы QA.
